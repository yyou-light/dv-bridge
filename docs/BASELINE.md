# 0.1.0 基线与验收

内容日期：2026-11-15。

## 来源部署已经确认

- 一个长期文件端点、五个 Terminal Worker；真实单路和五路合成任务通过。
- 64 KiB UTF-8 文本往返及字节/SHA256 校验通过；已完成波形的根、定点值和变化查询通过。
- 本地批量客户端 17 项检查、五条各一秒的真实合成派单和批量结果取回通过。
- 同样五次只读控制查询：原逐条调用 22.52 秒，优化后逐条 14.56 秒，批量 8.64 秒。单次中位数 3.88 → 2.48 秒。小样本结果，不代表仿真计算加速或延迟保证。

这些来源验收不携带账号、主机、业务路径、实际证书、日志或波形数据进入发布包。

## 分享版增加的内容

账号、目录、Python、队列、权限与后端设置集中到私有配置；运行时代码保留一份；Windows 客户端不再从旧 Runner 客户端导入清单。初次安装生成每人自己的身份，日常用短命令启动。

分享版新增初装、配置验证和站点适配属于新的代码路径。本机 Windows/Python 3.13 的完整隔离回归共 87 项：85 项通过，2 项平台相关跳过（Linux 初装与 POSIX 符号链接检查）。Windows 新副本的初装、私有目录、真实合成身份生成及公钥引导包排除私钥检查已通过。发布清单和逐文件摘要检查通过。

仓库 CI 在 Linux/Windows 上运行同一套合成测试；不接入 ETX，不运行商业 EDA。没有用另一账号的新 ETX 会话验收，不能宣称所有用户克隆即可零配置运行。
